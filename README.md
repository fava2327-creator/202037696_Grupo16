Lenguajes Interpretados – Integración de Módulos

Tarea 5: Componente Práctico

Descripción del proyecto

Este repositorio contiene los aportes desarrollados por los integrantes del Grupo 16 para la actividad práctica del curso Lenguajes Interpretados de la Universidad Nacional Abierta y a Distancia (UNAD).

El proyecto tiene como propósito integrar los scripts de control elaborados en la Tarea 2 y los diccionarios de registros desarrollados en la Tarea 3, mediante el uso de Python y herramientas de control de versiones.

Descripción del sistema

La actividad reúne diferentes módulos de programación relacionados con escenarios de instrumentación y automatización. Cada integrante aporta sus desarrollos individuales para facilitar la integración, organización y revisión del código del equipo.

La consolidación de estos módulos permite fortalecer el trabajo colaborativo y aplicar buenas prácticas de programación, documentación y gestión de versiones.

Componentes principales

Scripts de control correspondientes a los escenarios desarrollados en la Tarea 2.

Diccionarios de registros y estructuras de datos elaborados en la Tarea 3.

Organización de archivos Python dentro de un repositorio común.

Integración de los aportes individuales mediante Git y GitHub.

Seguimiento de cambios a través del historial de commits.

Revisión y consolidación de los módulos para construir una solución conjunta.

Tecnologías utilizadas

Python: desarrollo de los scripts y estructuras de datos.

Git: control de versiones y seguimiento de modificaciones.

GitHub: almacenamiento del repositorio y colaboración entre integrantes.

Objetivo

Integrar los desarrollos individuales de las tareas anteriores en un repositorio colaborativo, aplicando herramientas de control de versiones y buenas prácticas de programación, con el fin de consolidar una solución organizada, funcional y documentada.

Organización del repositorio

Los archivos del proyecto se encuentran organizados por módulos y escenarios, con el propósito de facilitar su identificación, revisión e integración.

Cada integrante es responsable de aportar sus archivos, documentar los cambios realizados y verificar que sus contribuciones se encuentren correctamente publicadas en el repositorio.

Trabajo colaborativo

La integración del proyecto se realiza mediante Git y GitHub. Los aportes se registran a través de commits, permitiendo identificar los cambios realizados por cada integrante y mantener un historial del desarrollo.

Este repositorio representa el trabajo colaborativo del Grupo 16 y constituye el espacio de consolidación de los módulos desarrollados durante las tareas anteriores.
